# 크루당 공지

앱이 켜질 때 읽는 공지 파일 한 장. 서버도 SDK도 없고, 이 리포의
`notice.json`이 전부입니다. 고쳐서 푸시하면 **5분 안에**(raw
`max-age=300`) 모든 기기에 닿습니다 — 심사가 필요 없습니다.

앱 소스는 비공개 리포에 있습니다. 여기엔 공지 글만 들어갑니다.

## 형식

```json
[
  { "id": "2026-11-01-price", "date": "2026년 11월 1일",
    "title": "평생 이용권 가격 안내", "body": "…", "popup": true },
  { "id": "2026-10-20-standby", "date": "2026년 10월 20일",
    "title": "대기(STBY) 일정도 읽습니다", "body": "…" }
]
```

| 필드 | | |
|---|---|---|
| `id` | 필수 | 공지를 구분하는 값. `날짜-주제`로 유일하게. |
| `title` | 필수 | 목록 제목이자 팝업 제목. |
| `body` | 필수 | 본문. 팝업으로 뜰 글은 두세 문장까지. |
| `date` | 선택 | 목록에 그대로 찍는 글자. 없으면 날짜 줄이 안 섭니다. |
| `popup` | 선택 | `true`면 앱을 열 때 한 번 뜹니다. 기본은 목록에만. |

## 규칙

- **맨 위가 최신.** 정렬은 파일 순서가 맡습니다.
- **`popup: true`는 아껴 씁니다.** 가격 변경, 환불 정책, 점검 정도.
  여러 건에 달아도 한 번에 하나만, 위에서 첫 번째가 뜹니다.
- **고치고도 다시 알리려면 `id`를 바꿉니다.** id가 같으면 이미 확인한
  사람에겐 뜨지 않습니다. 오타 수정은 id 그대로 두세요.
- **내릴 때는 배열에서 뺍니다.** 전부 내리려면 `[]`.
  이미 뜬 팝업은 되돌릴 수 없어, 잘못 올렸으면 새 공지로 정정합니다.
- **모든 버전이 같은 파일을 봅니다.** 구버전만 겨냥한 공지는 아직 못 합니다.

## 올리기

```sh
python3 -m json.tool notice.json > /dev/null   # 깨졌는지 먼저
git commit -am "공지: 평생 이용권 가격 안내" && git push
```

깨진 JSON을 올려도 앱은 받아 둔 공지를 그대로 보여 줍니다 — 사용자에게
깨진 화면이 뜨지는 않고, 새 공지가 안 나갈 뿐입니다. 그래서 눈치채기까지
시간이 걸리니 올리기 전에 한 번 보는 편이 낫습니다.
